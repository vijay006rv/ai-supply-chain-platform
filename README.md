# AI Supply Chain Platform

## 📌 Overview
This project is an AI-powered supply chain platform that helps in:
- Demand forecasting
- ESG analysis
- Geo-risk analysis
- Supply chain optimization
- Scenario simulation

## 🧠 Tech Stack
- Python
- Machine Learning
- React.js
- Node.js
- Tailwind CSS

## 🚀 Features
- Demand prediction using ML models
- ESG (Environmental, Social, Governance) analysis
- Geo-risk visualization
- Optimization engine
- Interactive dashboard

## ▶️ How to Run

### Backend
pip install -r requirements.txt
python backend/app.py

### Frontend
cd frontend
npm install
npm start

## ⚠️ Note
Dataset and API keys are not included for security reasons.
